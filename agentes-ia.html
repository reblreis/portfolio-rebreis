Agentes de IA com Java

Projetos de estudo para desenvolver APIs com Java e Spring Boot e explorar padrões de aplicações baseadas em modelos de linguagem.

api-multiagent

Projeto de API para experimentar uma arquitetura de múltiplos agentes, com tipos de agente e serviço orquestrador em uma aplicação Java/Spring Boot.

api-rag

Projeto de estudo voltado à exploração de uma API com recuperação de informações e IA generativa. Os componentes específicos de RAG devem ser descritos conforme estiverem implementados e testados.
