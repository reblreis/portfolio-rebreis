ConnectFlow

Aplicação Full Stack para praticar desenvolvimento de API REST com Java e Spring Boot, persistência relacional e interface Angular.

Back-end

  • Java 21 e Spring Boot
  • API REST organizada em camadas Controller, Service e Repository
  • Persistência com Spring Data JPA
  • Banco de dados PostgreSQL
  • Validações e operações de cadastro e consulta

Front-end e execução

  • Interface com Angular e TypeScript
  • Comunicação com a API REST
  • Docker para apoiar o ambiente de desenvolvimento

Tecnologias

Java 21Spring BootRESTPostgreSQLJPAAngularDocker
